# Processing sketches

Early creative coding experiments in Processing's Java mode:

- `ColorAndShapeArt`: a seeded grid of random color and shape compositions. Click to redraw; press **s** to save a numbered JPEG in the sketch folder.
- `ChangeOfStrokeWeight`: draw with the mouse; horizontal movement speed controls the stroke weight.
- `AbstractDropletsFallingShapeAndColor`: falling forms and a blue gradient, rendered as an animation.

Open a sketch's `.pde` file in [Processing](https://processing.org/download), select Java mode, and press **Run**. Each folder is a separate sketch. There are no additional library dependencies.

These are learning and visual experiments rather than packaged applications.
